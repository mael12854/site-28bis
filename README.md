# site-28bis

Le site de la maison du 28bis avenue de la République, 91430 Igny — statique, sans build.

## Structure

- `index.html` — la page d'accueil
- `galerie.html` — galerie photo
- `journal.html` — journal de la maison (vide pour l'instant ; pas de CMS, ajouter les billets à la main dans cette page)
- `charte.html` — la charte graphique (identité, couleurs, typographie, matières, applications)
- `photos/` — maison.png, cloture.png, portail.png

Contact : mailto:maison-28bis@yopmail.com (lien "Nous écrire" dans la navigation et le pied de page).

## Développement

Site statique, sans build. Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```
npx serve .
```
